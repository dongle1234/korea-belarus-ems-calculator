# 한국 → 벨라루스 EMS 택배 계산기

우체국 국제특급(EMS) 공식 요금표 기준 계산기. 정적 페이지라 GitHub Pages로 바로 열 수 있다.

**라이브:** GitHub Pages 활성화 후 `https://dongle1234.github.io/korea-belarus-ems-calculator/` (Settings → Pages → Branch `main`)

## 공식

```
부피중량(kg) = 가로 × 세로 × 높이(cm) ÷ 6,000
요금적용중량 = max(실중량, 부피중량)
총요금 = 3지역 요금표에서 적용중량을 올림한 구간의 요금 (− 사전접수 5% 할인)
```

- 벨라루스 = **3지역**
- 비서류(소포): 최대 **20kg**, 서류: 최대 **2kg**
- 최대규격: 길이 ≤ 1.5m, 길이 + 둘레 ≤ 3m
- 비서류 요금은 **2026.7.1부터 추가운송수수료 포함 요금**이라 별도 추가운송수수료는 0원이다.

## 검증 사례 (우체국 조회 화면 실측)

| 항목 | 값 |
|---|---|
| 도착국 | 벨라루스 BY |
| 실중량 | 8,220 g |
| 박스 | 41 × 31 × 28 cm |
| 부피중량 | 5,931 g (41×31×28÷6,000 = 5,931.3) |
| 요금적용중량 | 8.22 kg → 8.5 kg 구간 |
| 총요금 | **128,500 원** (요금 128,500 / 부가요금 0 / 추가운송수수료 0) |

계산기 결과와 우체국 화면이 일치한다.
