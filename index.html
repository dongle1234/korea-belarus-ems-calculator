우체국 국제특급(EMS) 공식 요금표 기준 · 벨라루스는 3지역 · 비서류 최대 20kg

공식
부피중량(kg) = 가로 × 세로 × 높이(cm) ÷ 6,000
요금적용중량 = max(실중량, 부피중량) → 구간 상한까지 올림 → 3지역 요금표에서 조회
총요금 = 요금표 요금 − 사전접수 할인(5%, 해당 시)
최대규격: 길이 ≤ 1.5m, 길이 + 둘레 ≤ 3m

검증 사례 — 실중량 8,220g, 41×31×28cm → 부피중량 5,931g → 적용중량 8.22kg → 8.5kg 구간 → 128,500원. 우체국 조회 화면 실측과 일치.
